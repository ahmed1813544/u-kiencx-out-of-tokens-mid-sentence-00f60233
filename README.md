Entry for the [make.fun](https://make.fun/bounty/u-kiencx-out-of-tokens-mid-sentence-00f60233) bounty **"Out of Tokens, Mid-Sentence"**: a program that writes the funniest one-line error message an AI agent shows when it runs out of tokens mid-sentence.

## How it works

`main.py` (stdlib only, no network, no randomness) writes a single line of at most 140 characters to `/output/entry.txt` — or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set.

## Run it

```sh
python3 main.py
```

Two runs produce byte-identical output.
